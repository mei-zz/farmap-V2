# FarMap AI Engine V2 — Baseline V1

This is the frozen **measurement baseline**, not a quality claim. It was generated by:

```text
cd zhgy/zhgy
mvn -Dtest=AiEngineBaselineEvaluationTest test
```

The repeatable wrapper is [`scripts/run-ai-engine-v2-baseline.ps1`](../scripts/run-ai-engine-v2-baseline.ps1). The latest machine-readable artifact is written to `zhgy/zhgy/target/evaluation-results/baseline-v1.json`; the test-only artifact is intentionally not stored in Product Loop MySQL.

## Failure distribution

| Code | Count | Cases | Meaning |
| --- | ---: | --- | --- |
| `A04_TOOL_FAILURE_NOT_HANDLED` | 1 | `agent-error-006` | current bounded runtime terminates on tool failure; no recovery loop |
| `A08_UNSUPPORTED_ACTION` | 3 | `agent-approval-007`, `agent-optional-recommendation-009`, `agent-stable-provenance-010` | action proposals without fixture evidence are observable before approval |
| `R02_IRRELEVANT_EVIDENCE_RETRIEVED` | 1 | `rag-knowledge-irrelevant-011` | lexical retriever returns chunks for a no-match query |

The distribution is intentionally small and deterministic. It is a baseline to expand with expert-labelled and real failure cases, not a claim that these are all production failures.

## Known blind spots

- No live LLM calls, provider variability, token usage or latency distribution.
- Grounding checks citation identity, not entailment or agronomic correctness.
- The benchmark uses synthetic `TEST_FIXTURE` contexts and does not promote them to Knowledge or HistoricalCase.
- Historical retrieval is represented as `READY_EMPTY`; no verified historical case is fabricated.
- ExpertReview labels are not auto-scanned. Future datasets must select explicit review records or fixtures.
- Confidence calibration, contradiction handling, stale evidence, cross-modal score calibration and semantic recommendation safety are not yet measured.

## Regression gates proposed for Phase 1/2

1. Stable ID provenance and approval compliance remain 100%; any regression is a hard stop.
2. Evidence source/document/version integrity remains 100% for Knowledge evidence.
3. Tool recall must not decrease beyond a threshold to be fixed after a larger labelled baseline.
4. Unsupported action rate must not increase.
5. Retrieval Recall@5 must not regress without an explicit experiment record.
6. Any improvement must report per-case deltas and failure-code changes, not only one composite score.
